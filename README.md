# Emir Tesisat Antalya

Emir Tesisat Antalya'nın resmi tanıtım ve iletişim sitesi.

- Canlı site: https://emirtesisatantalya.com
- Hizmet bölgeleri: Kepez, Muratpaşa, Konyaaltı ve Döşemealtı
- Çalışma saatleri: Pazartesi–Cumartesi 09.00–19.00; Pazar kapalı

## Yapı

Site, GitHub Pages üzerinde çalışan yalın HTML, CSS ve JavaScript dosyalarından oluşur. Derleme adımı veya harici bir JavaScript bağımlılığı yoktur.
